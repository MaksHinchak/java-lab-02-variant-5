# Лабораторна робота №2 • Варіант 5

Класи та об’єкти: Date, Square, Balloon

Автор: Гінчак Максим Богданович, 241-А.

## Завдання

- 1. Date з трьома полями byte, трьома конструкторами та повним набором календарних операцій.
- 2. Square: периметр, площа й довжина обох діагоналей.
- 3. Balloon: об’єм перетину й об’єднання двох куль, шість цілих аргументів командного рядка.
- Спільні вимоги: продемонструвати методи, статичні члени, toString та equals; додатково реалізовано hashCode.

## Запуск в IntelliJ IDEA

Відкрийте **саме цю папку Lab02** через File → Open → New Window. Це самостійний проєкт, який не потребує сусідніх лабораторних. Оберіть JDK 17+ у File → Project Structure → Project SDK. На підготовленому Mac вже налаштовано `JBR-25-labs`.

У списку конфігурацій виберіть `Lab02_Main` і натисніть Run. Робоча тека - корінь цього проєкту.

`Lab02_Demo` запускає кулі з аргументами `0 0 2 2 0 2`.

## Запуск у терміналі

```sh
./run.sh
./test.sh
```

Скрипти беруть JDK із JAVA_HOME, установленої IntelliJ або PATH. Для Windows: створіть папку out, виконайте `javac -encoding UTF-8 --release 17 -d out src/*.java`, потім `java -cp out Main` (у PowerShell перелік файлів можна передати через `Get-ChildItem src -Filter *.java`).

## Демонстрація

1. Дата: 2024.02.28, зміщення 2. Перевір +2 = 2024.03.01, -2 = 2024.02.26; програма також демонструє getters, setters, порівняння та копіювання.
2. Квадрат: сторона 3; P=12, S=9, d≈4.242640687.
3. Конфігурація Lab02_Demo має аргументи 0 0 2 2 0 2. Перетин ≈10.471975512, об’єднання ≈56.548667765.
4. Спробуй 2025.02.29 і поясни календарну помилку. Порівняй однакові, дотичні та вкладені кулі.

## Уточнення умови

- Методичка вимагає три byte-поля Date: обрано роки 1872..2127 зі зміщенням від 2000. Це обмеження явно повідомляється.
- Куля в просторі потребує x,y,z,r, але в умові задано лише 3 числа на кулю й 6 на запуск. Трактування: x,y,r; обидва центри мають z=0. Це саме об’єми куль, а не площі кіл.
- Нульовий радіус Balloon дозволено як вироджену кулю. Різниця дат знакова.
